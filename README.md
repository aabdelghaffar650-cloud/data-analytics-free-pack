# Data Analytics Free Pack

A practical collection of free resources for data analysts and learners, created by **Ahmed Mohamed Abd Elghaffar**.

The pack includes practical learning resources for:

- Power BI
- DAX
- SQL
- Tableau
- Python Data Analysis
- DataBridge AI

## What's included

### Power BI
Practical Power BI resources covering data preparation, modeling, dashboards, reporting, and real-world analysis.

### DAX
A focused guide covering DAX fundamentals, measures, filter context, evaluation context, and practical examples.

### SQL
A structured SQL learning resource with practical queries and examples for data analysis.

### Tableau
A real-world Tableau data analysis package with datasets, workbook resources, screenshots, case study material, and documentation.

### Python Data Analysis Quick Guide
A compact reference for essential Python, pandas, NumPy, data cleaning, exploration, and analysis commands.

### DataBridge AI
A practical analytics platform for importing, validating, cleaning, mapping, analyzing, and monitoring data.
